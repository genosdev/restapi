# GEN REST API

Dashboard scraper berbasis browser. Neobrutalism UI, no emoji, terminal response.
Author: GENOS

## Struktur
- `index.html` — main entry
- `style.css` — styling neobrutalism
- `app.js` — logic aplikasi
- `assets/` — foto + video (bos upload)
- `scrapers/` — modular scraper system

## Deploy ke Netlify
1. Push repo ke GitHub
2. Netlify → Add new site → Import from Git
3. Pilih repo → Deploy
4. Build command: (kosong)
5. Publish directory: `/`

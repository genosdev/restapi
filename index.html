GEN REST API

Kumpulan endpoint scraper siap pakai. Satu dashboard, banyak kategori — AI, Tools, Downloader, Premium, Utility. Eksekusi langsung dari browser tanpa setup. Setiap response ditandatangani oleh GENOS.

response.json 
{
  "author": "GENOS",
  "powered_by": "GEN REST API",
  "ok": true,
  "data": {
    "message": "Hello Bos!"
  }
}

KELEBIHAN

CEPAT & RINGAN

Endpoint dieksekusi langsung dari browser. Tanpa build step, tanpa dependencies.

MODULAR SCRAPER

Tambah scraper baru cukup di satu file. Struktur bersih, gampang dimaintain.

TERMINAL RESPONSE

Output JSON dirapikan, di-highlight, plus author GENOS otomatis di setiap response.

REALTIME STATUS

Loading animation live saat menembak server. Status jelas: connecting, receiving, done.

NO RATE LIMIT UI

Bebas eksekusi berulang. Riwayat output tampil di terminal, tinggal scroll.

PUBLIC ENDPOINT

Bisa dipanggil dari script apapun — cURL, Postman, Python, Node.js, Bot.

DOCS / USAGE

CARA PAKAI DI UI

  1. Buka menu EXPLORER di sidebar.
  2. Pilih kategori (TOOLS, PREMIUM, dll).
  3. Klik salah satu kartu endpoint.
  4. Isi parameter di panel kiri.
  5. Klik EXECUTE dan lihat output di terminal.

PAKAI DI SCRIPT LUAR

Setiap endpoint bisa dipanggil sebagai REST API:

# cURL
curl -X POST https://<site>.netlify.app/tools/rfweb2apk \
  -H "Content-Type: application/json" \
  -d '{"url":"https://tokosaya.com","app_name":"Toko Saya"}'

# JavaScript
const r = await fetch("https://<site>.netlify.app/premium/am-send", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ email: "user@gmail.com" }),
});
const data = await r.json();
console.log(data);
